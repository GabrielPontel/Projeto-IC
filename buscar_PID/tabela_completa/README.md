# Tabela completa da busca do PID

As 58 combinações de ganhos testadas na [fase de refinamento](../README.md#3-fase-2-refinamento-do-pid), na ordem em que foram testadas. Os dados brutos de cada corrida estão em [`../dados/2_refinamento_thr1150/`](../dados/2_refinamento_thr1150).

## Como ler as colunas

| Coluna | O que é |
|---|---|
| Kp, Ki, Kd | Ganhos do PID testados |
| Corridas | Quantas vezes essa combinação foi testada |
| Nota | Erro médio \|roll\| em toda a fase armada (inclui o transitório) + desvio do roll nos últimos 20 s, em graus. **Menor = melhor** (média das corridas) |
| Assentamento | Tempo até o \|roll\| ficar em ≤ 2° |
| Pico (>3 s) | Maior \|roll\| depois dos 3 primeiros segundos |
| Desvio motor 1 | Desvio padrão do comando do motor 1 nos últimos 20 s (tremor do motor) |
| Dentro de ±1° | Porcentagem do tempo, depois de assentar, com \|roll\| ≤ 1° |
| Status | OK ou REPROVADO pelos limites definidos no README principal; a marca MELHOR indica o PID final |
